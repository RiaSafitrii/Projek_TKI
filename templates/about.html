Tentang Sistem

BookFinder merupakan Sistem Temu Kembali Informasi (STKI) yang digunakan untuk melakukan pencarian buku berdasarkan kata kunci yang dimasukkan oleh pengguna.

Sistem ini menggunakan metode TF-IDF (Term Frequency-Inverse Document Frequency), BM25, dan Cosine Similarity untuk menentukan tingkat relevansi dokumen terhadap query yang diberikan pengguna.

Teknologi yang Digunakan

  • Python
  • Flask
  • TF-IDF
  • BM25
  • Cosine Similarity
  • Tailwind CSS
  • HTML
  • JavaScript
